# Skin Care Management System

This is a web-based **Skin Care Management System** designed to manage client profiles, skincare routines, products, and consultation appointments efficiently.

---

##  Features

* **Client Profile Management:** Track skin types, specific concerns, and personal history.
* **Personalized Routine Builder:** Set up custom Morning (AM) and Night (PM) skincare routines.
* **Product & Inventory Management:** Manage skincare items, active ingredients, and stock levels.
* **Appointment Scheduling:** Book and manage consultations with skin specialists.
* **Database Integration:** Pre-configured MySQL database support using phpMyAdmin.

---

##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL (phpMyAdmin)

---

##  How to Setup & Run

1. **Clone the Repository:**
   ```bash
   git clone (https://github.com/Moni-software/skincare-management-system.git)

2. Database Configuration:

Open phpMyAdmin (http://localhost/phpmyadmin).

Create a new database.

Go to the Import tab, choose the .sql file included in this project, and click Import.

3. Run the Project:

Move the project folder inside XAMPP htdocs or WAMP www directory.

Open browser and go to: http://localhost/skincare-management-system/home.php
